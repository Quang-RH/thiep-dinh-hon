# Thiệp mời đám hỏi — Đắc Quang & Trúc Nhi

Thiệp mời lễ đính hôn, phong cách chibi. Trang tĩnh 1 file, không cần build.

**Xem:** https://quang-rh.github.io/thiep-dinh-hon/

## Sửa nội dung

Mở `index.html`, tìm khối `const CONFIG` ở đầu phần `<script>` — tên, ngày giờ,
hai họ, địa điểm, chương trình lễ, mâm quả, bản đồ, nhạc nền, link nhận xác nhận
đều nằm ở đó. Sửa xong `git commit` + `git push` là trang tự cập nhật.
